# ⭐ Stellar Diary

**Stellar Diary** é um diário digital leve para registrar seus dias, humor, reflexões, gratidões e pequenas conquistas.

> “Cada dia tem uma luz própria. Registre-a antes que ela se apague.”

## ✨ Recursos

- Registro de humor do dia
- Título e texto para reflexões
- Campo de gratidão
- Campo de pequena conquista
- Filtro por humor
- Tema claro e escuro
- Salvamento automático no navegador
- Exportação dos registros em JSON
- Interface responsiva
- Sem instalação e sem dependências

## 🚀 Como usar

1. Abra o site publicado pelo GitHub Pages.
2. Escreva o título da sua entrada.
3. Escolha o humor do dia.
4. Escreva sua reflexão.
5. Adicione uma gratidão e uma conquista, se quiser.
6. Clique em **Salvar entrada**.
7. Os dados ficam salvos no navegador.

## 🧪 Tecnologias

- HTML5
- CSS3
- JavaScript puro
- LocalStorage
